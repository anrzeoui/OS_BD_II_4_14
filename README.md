## Зорилго

First Fit, Best Fit, Worst Fit ашиглан залгаа санах ой хуваарилах,
чөлөөлөх, хөрш hole нэгтгэх, нягтруулах үйлдлийг туршина.
Энэ нь логик хаягийн симулятор; компьютерийн бодит RAM-ыг хуваарилахгүй.
Номын шаардлага: Operating System Concepts, 10th ed., Chapter 9,
Programming Projects, P-48–P-50.

## GUI

- Нийт bytes → Reset: шинэ санах ой, хуучин төлөв ба түүх арилна.
- PID, Bytes, F/B/W → RQ: хүсэлт; RL: PID-ийн санах ойг чөлөөлнө.
- C: процессын дараалал, хэмжээг хадгалж зүүн тийш нягтруулна.
- Демо бэлтгэх → Алхам / Тоглуулах / Зогсоох.
- `allocator>` талбарт номын командуудыг оруулж болно.
- JSON хадгалах: одоогийн төлөв, команд бүрийн өмнөх/дараах төлөвийг хадгална.
- Гар команд өгвөл автомат демо зогсож, демогийн үргэлжлэл цуцлагдана.

## Хэрэгжилтийн сонголт

PID давтагдахгүй; латин үсгээр эхэлсэн 1–32 тэмдэгт, үсэг/цифр/_ зөвшөөрнө.
Ижил хэмжээтэй hole-уудаас бага хаягтайг сонгоно. Хэмжээ bytes нэгжтэй.
Нийт хэмжээ 1..2^63-1; энэ нь симуляцийн тоо тул тэр хэмжээний RAM шаардахгүй.
Блокийн жагсаалт O(n) зай ашиглана; RQ, RL, C нь O(n) хугацаатай.
UI-ийн F = 1 - largest_hole / total_free (сул зай 0 бол 0) нь
тархсан сул зайн туслах үзүүлэлт; хүсэлт амжилттай болох магадлал биш.
