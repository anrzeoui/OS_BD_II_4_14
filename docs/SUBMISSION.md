## GitHub-д байрлуулах

GitHub дээр хоосон `os-memory-allocation` repository үүсгэнэ.
Доорх YOUR_ACCOUNT-ыг бодит хэрэглэгч/байгууллагын нэрээр солино.
Өмнө үүссэн repo-д ажиллаж байвал шинэ git init/remote add хийхгүй.

```bash
git init
git add .
git commit -m "Add memory allocator, GUI, tests and documentation"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/os-memory-allocation.git
git push -u origin main
```

Багийн гишүүд хамтран өөрчилж, тест давтсаны дараа эцсийн PDF-ээ шинэчилнэ.
Release бэлэн болсон үед:

```bash
git tag -a v1.0.0 -m "BD1 submission"
git push origin v1.0.0
```

## Peer review - хараахан гүйцэтгээгүй

Хуваарилалтын 3-р хуудсын II-4-14 мөрөнд шүүмжлэх код **V-2-2** гэж
бичсэн боловч багийн жагсаалтад энэ код харагдахгүй. Багшаас зөв кодыг
тодруулна; өөр кодоор дураараа орлуулахгүй. Peer Review-ийн дэлгэрэнгүй
заавар одоогийн гурван файлд тусдаа хавсаргагдаагүй.

1. Clone/build/run алхмыг тэмдэглэх.

3. Өөрийн boundary/error тест нэмэх.
4. UI ба бодит төлөв нийцэж байгааг шалгах.
5. Нотолгоо, давтах алхам, сайжруулах саналтай Review.pdf гаргах.
6. Оноогдсон багийн Teams постын reply-д илгээх.
